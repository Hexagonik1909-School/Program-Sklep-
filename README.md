Program „Sklep” 
Program ma wspierać obsługę sklepu dowolnego rodzaju. Powinna być możliwość przyjęcia towaru do sklepu oraz jego sprzedaż w sposób hurtowy i detaliczny. Dla sprzedaży hurtowej powinna być możliwość rejestrowania stałych klientów. „Sprzedaż” ma polegać na wybieraniu towarów do koszyka, naliczaniu zbiorczej ceny, zapłatę z pieniędzy posiadanych w portfelu oraz usuwanie „sprzedanych” towarów z magazynu.


ASCII GUI - sklep internetowy dzielony na 3 GUI, admin GUI, user GUI, shopping GUI,

Admin - dodawanie towarów do sklepu, stan magazynu sklepu i jego stabilizacja z faktycznym stanem w sklepie, dostęp do edycji sklepu
User - Edycja dotycząca swojego profilu sklepu, tworzenie konta lub logowanie na istniejące
Shop - kupowanie przedmiotów , dodawanie je do koszyka, przeszukiwanie produktów dostępnych w sklepie podzielone na kategorie i filtrowanie produktów dostępnych i sprzedawanych(niedostępnych)

Zapis stanu sklepu poprzez bibliotekę json lnohmann
